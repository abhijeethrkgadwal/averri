Why I started Averri

Agents are capable. Intent was missing.

I watched what coding agents could do—and what went wrong when a particular section of software never clearly stated why it existed. The model saw working code. It assumed that was enough. It did not see the decision behind the code: who may call a route, what must never happen twice, which page is read-only, why a flow was designed that way.

That gap creates a quiet kind of risk. An agent can write something that compiles, passes the tests it wrote in the same session, and still interrupt a user flow that was already working. A smarter model does not fix this by itself, because the rules were never in the code.

So I wanted a strict layer agents could read before they change things, and that teams could check before a pull request merges: what changed, whether a rule was weakened, and why the original decision was taken. That is Averri—a rule engine for agents, declared in ordinary TypeScript, free and open source.

Not a company. Not a paid tier. An Apache-2.0 project so anyone can use it, challenge it, or prove it wrong.

Open source

What Averri is

A free tool for TypeScript backends. You declare who may do what, what must stay true, and why. Averri turns that into a semantic graph agents can query over MCP, and into generated tests that prove the rules hold. No telemetry. No rewrite of your app. Pre-alpha, honest about its limits.

Frequently asked

Who is Abhijeeth Gadwal?

Abhijeeth Gadwal is a product leader, AI product manager, technical product builder and open-source creator. He founded Averri, creates LocalDocu and Ownhand, and founded Davnix Tech.

Who created Averri?

Averri was created and is curated by Abhijeeth Gadwal. It is free and open source under the Apache-2.0 license, built with the help of AI coding agents.

Why did Abhijeeth Gadwal start Averri?

He saw what coding agents can do, and what breaks when a section of software never states its intent. Agents treat working code as just code, miss why a decision was taken, and can interrupt a user flow before a pull request merges. Averri makes those rules and that intent checkable.

Is Averri a company or a paid product?

No. Averri is a free, Apache-2.0 open-source community project. There is no paid tier, no telemetry and no hosted service. Abhijeeth built it in the open after reviewers advised against founding a company around it.
