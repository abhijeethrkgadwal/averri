# Averri brand assets

Free to use when referring to Averri.

| File | Use |
|---|---|
| `averri-logo-dark.svg` / `.png` | Logo for dark backgrounds |
| `averri-logo-light.svg` / `.png` | Logo for light backgrounds |
| `averri-mark.svg` / `.png` | The seal on its own, dark backgrounds |
| `averri-mark-light.svg` | The seal on its own, light backgrounds |
| `averri-avatar.svg` / `.png` | Profile picture for GitHub, npm, LinkedIn and social accounts |
| `averri-wordmark-dark.svg`, `averri-wordmark-light.svg` | Lettering only |

Colours: ink `#0b0f17`, teal `#5eead4`, deep teal `#0d9488` (on light backgrounds), text `#e9eef5`.
Typefaces: Space Grotesk (headings, logo) and Inter (body), both under the SIL Open Font License.

The seal: a hexagon whose corner nodes are the semantic graph, with a check for verified facts.
The name comes from "aver", to state something as true.
