# Warrant: 2027-2030 Future-Market Analysis (AI-systems researcher view, 23 Oct 2026)

## 1. Trend lines with evidence

**Share of code written by agents.** Vendor self-reports are high and rising: Google ~75% of new code AI-generated and engineer-approved (Apr 2026), Anthropic >80% of merged lines by Claude (May 2026), Microsoft ~30% ([digitalapplied roundup](https://www.digitalapplied.com/blog/ai-share-of-own-work-tech-companies-disclosed-figures), [New Relic 2026 AI Code Report](https://newrelic.com/sites/default/files/2026-06/New-Relic-2026-AI-Code-Report-06-09-2026.pdf)). Third-party measures are lower but still large: DX ~52% across 400+ companies, Sonar ~42%, and JetBrains finds only ~10% is *agent*-generated for manual coders ([JetBrains Research](https://blog.jetbrains.com/research/2026/08/how-much-code-do-developers-really-let-agents-write/)). Base-case extrapolation: 60-80% of merged backend code in TypeScript SaaS shops is agent-authored by 2028. This is the single most favorable trend for Warrant: the volume of code needing governance grows faster than the humans who review it.

**Capability benchmarks.** SWE-bench Verified is saturated (~79% official; 90%+ claims unverified) and OpenAI has stopped reporting it; SWE-bench Pro public set is ~62% and the private subset ~15-25%; Terminal-Bench 2.0 top ~82% ([developersdigest](https://www.developersdigest.tech/benchmarks/swe-bench), [codesota](https://www.codesota.com/benchmark/terminal-bench), [Vaughan](https://codex.danielvaughan.com/2026/03/26/codex-cli-benchmarks-real-world/)). METR's 50% time horizon reached ~12-14 hours with Opus 4.6; post-2024 doubling estimates range 3-4 months, with huge CIs, and METR itself warns a 50% horizon says nothing about the 98%+ reliability production code needs ([METR note](https://metr.org/notes/2026-01-22-time-horizon-limitations/), [tracker](https://ai2027-tracker.com/predictions/metr-doubling/)). Read: capability on isolated tasks is near-saturated; capability on messy, policy-laden repo tasks is not, and the reliability gap is where Warrant lives.

**Security quality is flat.** Veracode's 2026 report: syntax is near-perfect but secure-code rates have "barely improved" across model generations, 45-70% of samples fail security tests, and the dominant failures are authorization and missing access control; a Dec 2025 study of five agentic platforms found API authorization logic failures the most common critical class ([CSA research note](https://labs.cloudsecurityalliance.org/research/csa-research-note-ai-codegen-vulnerability-debt-2026), [SD Times](https://sdtimes.com/agentic-security/veracode-finds-ai-generated-code-security-has-barely-improved-since-last-year/)). Supabase built Agent Skills specifically because agents skip RLS on exposed schemas ([Supabase](https://supabase.com/blog/supabase-agent-skills)). This is direct evidence that the "missing auth" class Warrant targets does not disappear with model scale.

**Token prices and context.** Frontier prices are ~88% below 2023 but rose 36% YoY in 2026 while mid-tier fell 36%; enterprise effective price fell to ~$0.68/M (Ramp) ([BenchLM](https://www.benchlm.ai/token-price-index), [Fortune](https://fortune.com/2026/09/09/ai-compute-tokens-cheaper-boom/)). 1M-token windows are now standard on 13+ models; effective context still degrades ([morphllm](https://www.morphllm.com/largest-context-window-llm)). Implication: any "save tokens" pitch is dead by 2027; the pitch must be correctness and governance.

**Vendor-shipped memory/LSP/review.** Claude Code has auto-memory (Feb 2026), LSP, worktree isolation, and Claude Code Security (Feb 2026 preview, reasoning-based vuln scanning, 500+ OSS CVEs) ([releasebot](https://releasebot.io/updates/anthropic/claude-code), [Hacker News](https://thehackernews.com/2026/02/anthropic-launches-claude-code-security.html)). Codex remembers preferences and reviews nearly every OpenAI internal PR ([OpenAI](https://openai.com/blog/scaling-codex-to-enterprises-worldwide)). GitHub Copilot review reads AGENTS.md/CLAUDE.md/REVIEW.md, has org-level custom instructions GA, but still only comments, never blocks ([GitHub changelog](https://github.blog/changelog/2026-04-02-copilot-organization-custom-instructions-are-generally-available/), [vpsranking](https://vpsranking.com/news/ai/ai-2026-08-07-github-code-quality-copilot-review/)). Cursor Bugbot has rules files and usage billing; Vercel Agent reviews every PR at $0.25/M tokens ([Cursor](https://cursor.com/help/ai-features/bugbot), [Vercel](https://vercel.com/changelog/vercel-agent-has-updated-pricing)). Navigation and generic review are commoditised; none carries machine-checked contracts.

**Formal verification by LLM.** Dafny verification rose 68% to 96% in a year; Verus ~44%, Lean ~27% on the vericoding benchmark; Goedel-Code-Prover hits 62% on AlgoVeri-Lean ([vericoding](https://arxiv.org/pdf/2509.22908), [Goedel](https://arxiv.org/pdf/2603.19329)). Postcondition inference is an active ACL 2026 topic, with the finding that single-pass LLM postconditions are "plausible but semantically wrong" ([SpecMind](https://arxiv.org/abs/2602.20610), [PostCondBench](https://arxiv.org/pdf/2605.03356)). Prisma Next already ships its schema as a deterministic JSON contract with agent skills ([Prisma](https://www.prisma.io/docs/orm/next)). Direction: specification *checking* is becoming cheap; specification *authority* (who decided the invariant) is not.

**Enterprise policy.** GitLab/Harris (n=1,528): 80% adopted AI faster than governance, 85% say the bottleneck moved to review/validation, 84% say the hard part is governing code after creation; Lineaje: 17% have full visibility; Salt: 38% still rely on manual review ([GitLab](https://s204.q4cdn.com/984476563/files/doc_news/GitLab-Research-Reveals-Organizations-Are-Generating-AI-Code-Faster-Than-They-Can-Control-It-2026.pdf), [Lineaje](https://securitybrief.co.uk/story/lineaje-survey-finds-ai-code-confidence-outpaces-visibility)). EU AI Act high-risk logging obligations (Art. 12/19) took effect Aug 2026, though coding assistants are mostly out of scope unless telemetry feeds HR monitoring ([Help Net Security](https://www.helpnetsecurity.com/2026/04/16/eu-ai-act-logging-requirements/)).

## 2. Three scenarios, 2027-2030

**Fast (P=0.30): models reach reliable multi-day autonomy by 2028, 98%-reliability horizons measured in days.** Agents write and verify most code; humans review spec diffs, not code. Need for an explicit contract layer *grows* in form but changes owner: the contract becomes the primary human artifact, and whoever owns the spec surface owns the workflow. Capture: model vendors and GitHub (65%), frameworks like Prisma Next/Convex (25%), independents (10%). The "agent-native language" thesis resolves toward a *semantic IR with contracts* but vendor-owned: Prisma's JSON contract, Anthropic/OpenAI spec formats, Kiro-style spec files. New human-facing syntax dies; direct-to-binary stays niche because humans still need auditable artifacts. An independent IR wins only if it is already a de facto standard with an installed base before 2028, which an M6-2027 launch cannot achieve.

**Medium (P=0.50): steady METR-style progress, saturated isolated benchmarks, persistently flat security quality, agents at 60-80% of code.** The contract layer need grows strongly: more code, same authorization-failure rate, review bottleneck confirmed by every survey. Capture is fragmented: GitHub owns the gate location (rulesets), Prisma owns data contracts, review bots (Copilot/Bugbot/Vercel/CodeRabbit) own probabilistic review, and there is a real gap for *deterministic, human-approved, action-level* contracts with impact analysis. Independents can hold 20-35% of this slice if they own the benchmark and attach to existing stacks. The language thesis: agents converge on existing languages plus library-shaped declaration layers (Zod/Drizzle/Convex pattern); bespoke syntax does not happen; the "winning representation" is TypeScript-embedded declarations compiled to a graph, exactly Warrant's V0 shape. Who is positioned: Prisma (data), Encore (framework), and whoever ships an attach-mode layer with a credible benchmark first.

**Slow (P=0.20): plateau at today's reliability, cost pressure, enterprise pullback on autonomy.** Contract-layer need grows modestly, framed as safety rails; budgets tighten and governance is bought from existing vendors (GitHub, GitLab, Snyk-class) rather than new ones. Agents stay on existing languages; the IR question is moot. Independents capture little unless bundled into a review/security suite.

Across scenarios, the probability that the *winning* agent representation is "semantic IR with contracts" rather than plain code plus prose specs: ~45%. The probability an *independent* company owns that IR: ~8%. The probability an independent owns a durable *governance layer on top* of whatever IR wins: ~30%.

## 3. "Will frontier models make this unnecessary?"

**Yes side.** Models already review nearly every PR at OpenAI and Vercel; Claude Code Security finds real CVEs by reasoning, not rules; postcondition inference and Dafny verification are improving fast; a model that writes better code writes better tests in the same session; memory and 1M context erase orientation cost. In a fast scenario, an agent can infer contracts from code and tests, generate auth matrices on demand, and flag weakening with no library installed. The structured-diagnostics advantage (RustAssistant-class) shrinks as models read noisy output well.

**No side.** Veracode's flat security curve across generations is the strongest counter: generation quality improved, authorization correctness did not, because the failure is *not knowing the invariant*, not inability to code it. SpecMind's finding that inferred postconditions are plausible but wrong is the same point: an LLM inferring contracts from code reproduces the code's bugs. Surveys say the bottleneck is now review and post-creation governance, which models accelerate but cannot legitimise. GitHub's own tooling still cannot block merges, and GitLab's 84% "governing after creation" number is a buyer statement.

**What remains structurally necessary regardless of model quality (P>0.85 each):** a shared, versioned source of truth for invariants across sessions, agents, and humans (memory is per-vendor and per-user; contracts must be in the repo); human-approved invariants with provenance (who decided "members cannot invite", when, why); deterministic derivation (gates, auth matrices, impact) that does not vary 30x run to run; and audit/governance evidence for SOC 2, PCI, and AI-Act-adjacent logging. **What dissolves (P>0.80 by 2028):** navigation and orientation tooling, boilerplate and layer-mismatch prevention as a selling point, generic test writing, token-efficiency claims, and cascade-collapsed diagnostics as a differentiator. Warrant's V0 scope correctly sits on the first list; its MCP find/overview tools sit on the second and should be treated as adoption glue, not value.

## 4. Platform-risk timeline (24 months, to Oct 2028)

Probability each ships a *native contract/policy/impact layer for agent-written backends*, defined as machine-checked declarations plus a PR gate or impact report, not prose rules:

- **GitHub:** 40%. Has rulesets, Code Quality, custom instructions, AGENTS.md; a "required semantic check" is one step away. Most likely to ship the *gate*, least likely to ship a TypeScript-aware contract language.
- **Prisma:** 55% for data-layer contracts (already shipping JSON contract and agent skills), 15% for action-level policies/workflows. Partial overlap, mostly complementary.
- **Anthropic:** 30%. Claude Code Security plus memory plus skills could become "Claude-verified invariants," but Anthropic's incentive is cross-repo model quality, not neutral governance; more likely to publish a spec format than a compiler.
- **OpenAI:** 25%. Codex review is strong; a contract layer is not in their product grammar.
- **Cursor:** 25%. Bugbot rules and learned-from-history review; a deterministic layer is off their roadmap style.
- **Vercel:** 20%. Vercel Agent is review-and-ops; backend contracts are not their surface.
- **Supabase:** 35% for RLS-centric policy checks exposed to agents (Agent Skills already); 10% for a general contract layer.
- **Any of the seven shipping something that captures >50% of Warrant's Team-tier value proposition:** ~60%. **Any shipping something that eliminates the Enterprise policy-gate value:** ~25%, because neutral, on-prem, cross-agent gates are structurally unattractive to vendors who each want their agent to be the one trusted.

## 5. Durable value for an independent in 2030

Ranked by expected durability: (1) **Enterprise governance** of agent-written backends (policy-as-code gates, contract audit trails, on-prem report server): P(durable independent niche exists)=0.60, but it is a $5-30M ARR category shared with GitLab, Snyk, and whoever GitHub partners with, not a venture outcome without a second product. (2) **Vertical compliance packs** (PCI/HIPAA/SOC 2 evidence derived from contract coverage): 0.50, higher margin, slower sales, strongest moat because regulators do not care which model wrote the code. (3) **Benchmark/eval ownership** (AgentCodeBench): 0.35 as a standalone asset; benchmarks are credibility and distribution, rarely revenue, and vendors co-opt them. (4) **The IR as a standard**: 0.08; Prisma, Anthropic's spec formats, or a foundation are far likelier owners, and the realistic best case is Warrant's declaration shape being absorbed into one of them. (5) **Nowhere**: 0.25, concentrated in the fast scenario where review-by-model plus GitHub rulesets is "good enough" for mid-market and only regulated enterprise pays.

## Future-market verdict

The market Warrant targets is real and growing on every measured axis that matters: agent-authored share heading to 60-80%, authorization-failure rates flat across model generations, and 80-85% of surveyed organisations naming post-creation governance as the bottleneck. The parts of the original vision that frontier models dissolve (navigation, boilerplate, token savings, test writing) are already dissolving, and the Warrant V0 correctly drops them. What survives through 2030 in every scenario is a human-approved, repo-resident, deterministically derived contract layer with governance evidence, and the medium scenario (50%) leaves a genuine independent niche for it. But the honest future-market picture is that this niche is a governance and compliance business worth perhaps $5-30M ARR to an independent, with ~60% odds that a platform ships the Team-tier half within 24 months and ~8% odds the IR itself becomes a standard anyone outside Prisma or a model vendor owns. The path to venture scale requires reaching an installed PR-bot base before GitHub turns rulesets into semantic gates, which is a 12-18 month window from today, for a founder with a second startup launching this month. My verdict is a conditional **BUILD on a narrow, kill-gated basis, and PASS on the vision**: build only the attach-mode contract library plus PR bot aimed at regulated TypeScript SaaS teams, with the M4 N=10 benchmark gate kept as written, accept that the realistic outcome is a profitable governance tool or an acquisition by Prisma, GitHub, or a security vendor rather than a platform, and abandon it at M6 if the gain over a documented repo with Claude Code Security and Copilot review is under the pre-registered bar. If the founder cannot commit full focus for those 6 months because of the kids-content launch, the window argument says pass now rather than build slowly: in this market a half-speed Warrant arrives after GitHub.
